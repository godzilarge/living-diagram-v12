## Seven grounded candidates, by resonance

1. **The Swiss network graphic timetable (Netzgrafik)** — nodes as station boxes, lines with the minute at each
   end; white, black, one red. Carries "port at both ends of every cable" literally.
2. **The transit map (Beck)** — schematic lines classed by colour, interchanges as the cores. Strong map identity;
   octolinear routing fights memorized free placement.
3. **The engineering drawing** — ink on white, title block, grid references, **revision clouds** for what changed.
   Diff as revision; run as revision index.
4. **The printed circuit board** — solder-mask ground, copper traces, silkscreen reference designators. Dark-scene
   friendly; traces at 45° as routing move.
5. **The Swiss topographic map** — sites as terrain, cables as roads classed by capacity, legend as first-class.
6. **The dressed rack: patch-cord colour code and label-maker labels** — cables in the cord colours of their media,
   a boot with a flag label at each end carrying the port name; label type. ← **assigned by the roll**
7. **The patent / technical illustration** — monochrome, leader lines with reference numerals, hatching.

## Challengers dealt, fused, judged (audience identification × product clarity)

- **Emission-line rail**: one off-centre rail owns navigation; state as line form, not hue. Fused: a map cannot hang
  off one rail. **Declined.** Discipline kept: *state carried in line form (solid live, dashed pending, half-height
  stale, struck removed), never only in hue* → raised into the assigned direction, whose cord colours already carry
  media.
- **Japanese high-density web**: hairline modules, utility red tabs, nothing wasted. Fused: a dense inspector, but a
  map is not a mosaic, and "light to the eye" is a binding constraint. **Competitive on clarity (data side), loses
  identification.** Not built; its density discipline informs the panel of every direction.
- **Star atlas**: navy chart ground, magnitude-sized marks, chalk lines, red-flashlight amber for the object under
  the eye, a figure layer that fades up on request. Fused: device importance as size on a fixed ramp, sites as
  constellation figures, cables as faint chart lines, selection in night-vision amber. **Competitive**: wins
  identification on the night-operations scene, holds clarity if the chart's typographic rigour is kept. **Built**
  as the third direction.
- **Jet-age ticket wallet**: coupon book flow. Fused: a map is not a sequence. **Declined.** Discipline kept:
  *nothing disappears, it cancels* (a removed cable stays struck through for the compared run) → raised into the
  assigned direction.
- **Acetate tab board manual**: a stepped tab rail, leaves hinged over a board. **Declined** (reading artifact).
  Discipline kept: *the tab rail's height proportional to extent* → considered for the run band, not adopted.
- **Terminal yellow wayfinding**: one message per band line, sentence case, decisions ahead only. Fused: the
  selected device's panel shows the "choices ahead" (its neighbours, with the port that gets you there). **Declined
  on identification** (travellers, not engineers), its discipline *one message per line, sentence case* raised into
  the pick.

## Orhan's verdict on round 1 (2026-10-16 morning)

- **Scope correction**: "the UI" means the shell (navigation, menus, panels, search, tooltips). **The canvas (nodes,
  cables) is another surface, treated in its own later session.** Round 1 mixed both; round 2 is the shell only, the
  canvas neutralised.
- **Base = the category standard (`canon`), improved, with elements of `netzgrafik`.** `star-atlas` rejected outright
  on its palette ("the worst"). `patch-cord` not retained.
- **All four node renderings rejected**; the current v1 cards are judged better. Noted for the canvas session: start
  from the v1 cards.
- **Air and floating**: every mockup felt glued edge to edge; he wants floating elements that hide themselves and
  adapt to their content, a feeling of lightness.
- **Palette**: `netzgrafik`'s colours feel more alive (white, black, one strong accent).
- **A home page is missing**: a modular space of widgets (latest changes and by whom, the list of infrastructures),
  extensible over time. New surface, added to PRODUCT.md.
- **Organisation**: `canon`'s chrome felt unmastered, no hierarchy in where things sit.
- **Icons over words** for commands (Exporter, Modifier → icon only), with **one tooltip grammar for the whole
  application: white text on black**, modern, everywhere.
- **Search**: discreet and elegant, standard shortcut (Ctrl+K), opens a popup with the page fading behind; rich.
- **Motion**: rich transitions and movement, balanced, "not a discotheque".
- **View switch** (Diagramme / Contrôle / Journal): the thin coloured rail of `netzgrafik`, not big buttons.
- **Logo only**, no product name next to it.

## Orhan's verdict on round 2 (2026-10-16)

"I like the direction this v2 is taking." Kept as is: the tooltip grammar (for every tooltip of the application),
the home page ("exactly what I had in mind"), the floating panel. Five changes for round 2 bis:

1. **Home**: drop the "Recherche" widget (Ctrl+K already does it, and better); rebalance the grid.
2. **Panel**: a control in its header to **enlarge** it, and a **focus** mode that shows much more; **the richness
   of the `interfaces` topic must be readable** (description, mode and VLANs, MAC, IP, last change, media,
   transceiver…): "the richness of the collection has disappeared, lost in the bundle". Plain words stays the rule;
   hiding facts was never the brief.
3. **Run band**: move it to the bottom right, away from the canvas controls.
4. **Edit mode**: the v1 editing functions (add a link, a note, a shape, a table, an image, a code block, a
   connector, a group) return as a **vertical palette on the left**, shown in edit mode.
5. Accent: still to choose (A cobalt / B signal green).

# patch-cord — THE ROLL

**World**: the dressed rack. Patch cords in the colour of their media, dressed and labelled; a label-maker label
on every port; black boots with a flag label at each cord end. The graphic tradition every network engineer reads
daily in the server room, not the server room itself.

**Thesis**: every cable looks like the cord it is, and tells you its port at both ends.

**Palette (commit to it; name the exact values in DIRECTION.md)**
- Ground: a light, cool, neutral surface like label stock and painted cabinet steel (not pure white; not grey-on-grey).
- Cords, by media, the colour code of the trade: single-mode fibre **yellow**, OM3/OM4 multimode **aqua**, OM1/OM2
  **orange**, copper **blue**, HA heartbeat / management **red**, unknown media **grey**. These are the data colours;
  they are saturated and they are allowed to be loud, because they mean something.
- Ink: black; secondary text tinted from the ground, never flat grey.
- State on top of the palette only where it carries meaning: unreachable device, down port, error.
- **Raise 1 (from the emission-line challenger)**: cable **status is carried by line form, never by hue**: confirmed
  = solid, observed only = one line form, documented only = dashed, down = struck or half-weight. The cord colour says
  the media, the line form says what the data knows.
- **Raise 2 (from the jet-age wallet)**: nothing disappears, it cancels: a cable removed since the compared run stays
  drawn, struck through.

**Type**: the label-maker voice: a sturdy grotesk, medium weight, generous x-height, sentence case; names of devices
and ports in the same face (bold for the device name, regular for the port), tabular figures. Pick an OFL face with
that character (e.g. Barlow, Archivo, Hanken Grotesk, Public Sans, Figtree; **not** Inter, not IBM Plex, not Space
Grotesk, not DM Sans). Scale ratio ~1.15; one family.

**Density**: high and orderly, like a well-dressed rack: the panel's interface table is tight, aligned, scannable.

**Signature move, concretely**: each cable is a cord with a **black boot and a flag label at both ends** carrying the
port name (short form: Eth1/1, Te1/1/1, Po10), the flag always horizontal and readable; the legend of cord colours is
a first-class element of the chrome, not a footnote.

**Hold the world to its four contributions**: no faceplates, no cage nuts, no rack rails as decoration; devices are
standard cards (a sharp or barely rounded rectangle, type icon, name on the label); the chrome is a standard top bar
and a standard panel.

**Scene**: light (a lit server room, a projector). Say how the dark theme would go (the black cabinet).

**Honest risk**: the cord colours compete with state colours; the move becomes a costume if boots and flags get
decorative. Keep every label at one size.
